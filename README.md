## چرا این نسخه جداست؟

Subify اصلی روی Chrome/دسکتاپ کامل کار می‌کنه، چون دوبلهٔ زنده به گرفتن صدای تب (`chrome.tabCapture`) و یک سند پس‌زمینه (`chrome.offscreen`) نیاز داره. این دو API فقط در Chromium پیاده‌سازی شدن — نه Firefox (دسکتاپ یا اندروید) و نه Safari (iOS) اونا رو دارن. Subify Lite دقیقاً همون بخش ترجمهٔ زیرنویسه، بدون هر چیزی که به صدای تب نیاز داشته باشه.

## ✨ ویژگی‌ها

- 🌐 ترجمهٔ لحظه‌ای زیرنویس روی یوتیوب، ویمیو، آپارات و Coursera
- ⚡ ترجمهٔ پیش‌دستانه با همگام‌سازی دقیق زمانی
- 🧠 چند ارائه‌دهنده: Google Gemini · OpenRouter · OpenAI · یا هر Custom API
- 💾 خروجی زیرنویس SRT، VTT و TXT
- 🎨 استایل‌دهی کامل زیرنویس با پیش‌نمایش زنده
- 📚 یادگیری لغت با سیستم Leitner
- 📊 داشبورد آمار مصرف و برآورد هزینه
- 🔒 کاملاً محلی — جزئیات در [PRIVACY.md](PRIVACY.md)
