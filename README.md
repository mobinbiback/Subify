## 🌍 سابیفای چیه؟

**سابیفای یک افزونه رایگان و متن‌باز برای ترجمه، درک و یادگیری از محتوای چندزبانه در وب است**

با Subify می‌توانی محتوای ویدیویی و متنی را ترجمه کنی، زیرنویس دوزبانه داشته باشی، از قابلیت دوبله صوتی با هوش مصنوعی استفاده کنی، صفحات وب را ترجمه کنی و هنگام مواجهه با کلمات جدید، معنی آن‌ها را بررسی و برای یادگیری بعدی ذخیره کنی.

هدف Subify فقط ترجمه کردن نیست.

می‌خواهیم ترجمه را به چیزی نزدیک‌تر به تجربه واقعی یادگیری تبدیل کنیم:

**ببین. بفهم. یاد بگیر.**

---

## ✨ ویژگی‌ها

### 🌐 ترجمه هم‌زمان

محتوای گفتاری و زیرنویس را با استفاده از سرویس‌های هوش مصنوعی پشتیبانی‌شده ترجمه کن و ترجمه را هم‌زمان با محتوا دنبال کن.

### ⚡ ترجمه پیش‌دستانه

بخش‌های بعدی محتوا می‌توانند از قبل پردازش شوند تا ترجمه با تأخیر کمتری نسبت به پخش محتوا نمایش داده شود.

### 🔤 زیرنویس دوزبانه

متن اصلی و ترجمه را هم‌زمان ببین.

این حالت برای کسانی که در حال یادگیری زبان هستند، امکان مقایسه مستقیم جمله اصلی و ترجمه را فراهم می‌کند.

### 🎙️ دوبله با هوش مصنوعی

محتوای ویدیویی را با صدای ترجمه‌شده دنبال کن و تنظیمات مربوط به تجربه دوبله را کنترل کن.

از جمله:

- بلندی صدای دوبله
- کاهش صدای اصلی
- سرعت پخش
- انتخاب صدا

### 📄 ترجمه کامل صفحه

با قابلیت **Translate Page**، محتوای متنی صفحات وب را مستقیماً ترجمه کن.

ترجمه دیگر فقط به زیرنویس ویدیو محدود نیست.

### 📖 دیکشنری

کلمات و اصطلاحات جدید را هنگام تماشا یا مطالعه بررسی کن.

دیکشنری به تو کمک می‌کند معنی و اطلاعات مربوط به واژه را بدون خارج شدن از جریان محتوا بررسی کنی.

### 🧠 یادگیری و مرور واژگان

کلمات جدید را ذخیره کن و بعداً از طریق بخش **Learn** آن‌ها را مرور کن.

سیستم یادگیری واژگان Subify اطلاعات مربوط به کلمات را به‌صورت محلی نگهداری می‌کند و امکان مرور آن‌ها را فراهم می‌کند.

### 🎬 استوری بورد

از ابزارهای مرتبط با زیرنویس و Storyboard برای بررسی و کار با محتوای ویدیویی استفاده کن.

### 💾 خروجی زیرنویس

زیرنویس‌ها و ترجمه‌ها را در فرمت‌های مختلف ذخیره کن:

- SRT
- VTT
- TXT

### 🎨 شخصی‌سازی زیرنویس

ظاهر زیرنویس را مطابق سلیقه خودت تنظیم کن.

سابیفای از تنظیمات مختلف نمایش و فونت‌های مناسب برای زبان‌های مختلف، از جمله فونت‌های فارسی، پشتیبانی می‌کند.

### 🤖 سرویس‌های هوش مصنوعی

سابیفای از معماری Provider-based استفاده می‌کند تا بتوانی سرویس مورد استفاده برای قابلیت‌های هوش مصنوعی را انتخاب و پیکربندی کنی.

سرویس‌های فعلی شامل:

- Google Gemini
- OpenRouter
- OpenAI

### 🌍 محتوای چندزبانه

سابیفای برای کار با محتوای زبان‌های مختلف طراحی شده و مسیرهای ترجمه و یادگیری آن به یک زبان خاص محدود نیست.

---

## 🎯 چرا سابیفای؟

محتوای چندزبانه در اینترنت کم نیست.

ویدیوهای آموزشی، دوره‌های آنلاین، سخنرانی‌ها، پادکست‌ها و صفحات وب زیادی وجود دارند که ممکن است به زبان موردنظر ما نباشند.

مشکل همیشه پیدا کردن محتوا نیست.

**گاهی مشکل، فهمیدن آن است.**

سابیفای ابزارهای ترجمه، زیرنویس، دوبله، Dictionary و یادگیری واژگان را تا حد امکان نزدیک به خود محتوا قرار می‌دهد.

به‌جای اینکه بین چند ابزار مختلف جابه‌جا شوی:

**ببین، بفهم، یاد بگیر**

## 🚀 شروع سریع

1. سابیفای را از فروشگاه مرورگر خود نصب کن.
2. وارد تنظیمات افزونه شو.
3. سرویس و کلید API موردنظر خودت را تنظیم کن.
4. محتوای موردنظر را باز کن.
5. قابلیت ترجمه را فعال کن.
6. در صورت نیاز زیرنویس دوزبانه، دوبله، Dictionary یا ابزارهای یادگیری را استفاده کن.

## 🧠 سرویس‌های هوش مصنوعی

سابیفای از معماری مبتنی بر Provider استفاده می‌کند تا کاربر بتواند سرویس هوش مصنوعی موردنیاز خود را انتخاب و پیکربندی کند.

| سرویس | کاربرد |
|---|---|
| Google Gemini | ترجمه و قابلیت‌های زنده هوش مصنوعی |
| OpenRouter | ترجمه متنی با مدل‌های پشتیبانی‌شده |
| OpenAI | ترجمه متنی با API اوپن‌ای‌آی |

> **کلید API خودت را استفاده کن:** سابیفای برای استفاده با اعتبارنامه‌هایی که خود کاربر وارد می‌کند طراحی شده است.

---

## 🔐 حریم خصوصی

سابیفای با رویکرد **Local-first** طراحی شده است.

- تنظیمات و اطلاعات پیکربندی افزونه تا حد امکان به‌صورت محلی در مرورگر نگهداری می‌شوند.
- کلیدهای API واردشده توسط کاربر در تنظیمات افزونه نگهداری می‌شوند.
- درخواست‌های مربوط به هوش مصنوعی با سرویس و اعتبارنامه‌ای که کاربر تنظیم کرده ارسال می‌شوند.
- اطلاعات مربوط به یادگیری واژگان به‌صورت محلی در مرورگر ذخیره می‌شوند.

سابیفای برای این طراحی شده که کاربر کنترل بیشتری روی سرویس‌ها و اعتبارنامه‌های مورد استفاده خود داشته باشد.

## 🛠️ ساختار پروژه

```text
Subify/
├── manifest.json
├── popup.html / popup.js

├── background.js
├── content.css
├── page-bridge.js / page-hook.js
```

### بخش‌های اصلی

| فایل | نقش |
|---|---|
| `subtitle-overlay.js` | نمایش و همگام‌سازی زیرنویس |
| `live-client.js` | ارتباط با قابلیت‌های ترجمه زنده |
| `background.js` | Service Worker افزونه |
| `offscreen.js` | پردازش صوت موردنیاز برای قابلیت‌های صوتی |
| `learn.js` | سیستم یادگیری و مرور واژگان |
| `storyboard.js` | قابلیت‌های مربوط به Storyboard |

## 🤝 مشارکت

سابیفای یک پروژه متن‌باز است و از مشارکت توسعه‌دهندگان استقبال می‌کند.

```bash
git clone https://github.com/mobinbiback/Subify.git
cd Subify
```

سپس می‌توانی پروژه را به‌عنوان یک **Unpacked Extension** در مرورگر بارگذاری و توسعه آن را شروع کنی.

برای گزارش باگ، پیشنهاد قابلیت یا مشارکت در توسعه:

- یک Issue باز کن
- Pull Request ارسال کن
- تغییرات خود را با توضیح واضح ارائه بده

### روند پیشنهادی

```bash
git checkout -b feature/your-feature
git add .
git commit -m "Add your feature"
git push origin feature/your-feature
```

سپس یک Pull Request در GitHub ایجاد کن.
