# Support

Thank you for using Subify.

This document explains where to get help with Subify and how to report different types of issues.

## Getting Help

Before asking for help, please:

- Check the README and available documentation.
- Search existing GitHub Issues for similar problems.
- Make sure you are using a recent version of Subify.
- Include enough information for the issue to be reproduced.

## Bug Reports

If you believe you have found a bug that is not security-related, please open a GitHub Issue.

Please include:

- Subify version
- Browser and browser version
- Operating system
- Steps to reproduce the problem
- Expected behavior
- Actual behavior
- Relevant console errors or logs
- Screenshots or recordings when useful

## Feature Requests

If you have an idea for improving Subify, please open a feature request through GitHub Issues.

Please describe:

- The problem you are trying to solve
- Your proposed solution
- Why the feature would be useful
- Any alternative solutions you have considered

## Questions and General Support

For general questions about Subify, installation, configuration, or usage, please use GitHub Issues or Discussions when appropriate.

Please avoid opening multiple issues for the same question.

## Security Issues

Do not report security vulnerabilities through public GitHub Issues, Pull Requests, or Discussions.

For security-related issues, please follow the instructions in:

[SECURITY.md](SECURITY.md)
