کلیدهای API و سرویس‌ها

کلیدها فقط روی همین دستگاه (Storage محلی مرورگر) ذخیره می‌شن و جز به همان سرویسی که انتخاب کردی ارسال نمی‌شن. مدل هر سرویس از تب «ترجمه» در پاپ‌آپ انتخاب می‌شه.

کلید Gemini رو بگیر (رایگان، حدود ۳ دقیقه)

  1. این صفحه رو باز کن و با حساب گوگلت وارد شو: aistudio.google.com/app/apikey
  2. روی Create API key بزن. اگه پرسید پروژه می‌خوای، یه پروژهٔ جدید انتخاب کن.
  3. کلید رو کپی کن و توی کادر Gemini بالا بذار.
  4. «ذخیره کلیدها» رو بزن.

کلید Gemini برای همه‌چیز لازمه: زیرنویس، دوبله، واژه‌نامه و ترجمهٔ زنده. پلن رایگان سقف درخواست داره؛ اگه خطای quota دیدی، یه دقیقه صبر کن.

OpenRouter و OpenAI اختیاری‌ان. اگه کلید داری، همون کادرها رو پر کن.

نکته مهم: برای استفاده از Gemini، IP شما باید بدون نشتی (IP Leak) باشد.

API اختصاصی: سرویس خودت را اضافه کن

این بخش فقط برای سرویس‌هایی است که Gemini، OpenRouter یا OpenAI نیستند. اطلاعات API را از سایت همان سرویس کپی کن و اینجا وارد کن.

فقط همین ۴ چیز لازم است: اسم سرویس، آدرس API، کلید API و کد مدل. بعد «ذخیره و فعال‌سازی سرویس» را بزن.
۱ اطلاعات را وارد کن۲ ذخیره و فعال‌سازی سرویس۳ اتصال را تست کن۴ در «ترجمه» انتخابش کن
یک اسم ساده انتخاب کن؛ مثلاً «سرویس من».
آدرس API را دقیقاً از سایت سرویس کپی کن.
کلیدی که سرویس به تو داده را وارد کن.
کد مدل را دقیقاً از سایت سرویس کپی کن. اگر سرویس دکمه «دریافت مدل‌ها» دارد، می‌توانی از همان استفاده کنی.

حریم خصوصی و داده‌ها

کلیدهای API و تمام تنظیمات فقط روی همین دستگاه (Storage محلی مرورگر) ذخیره می‌شن و جز به همون سرویسی که خودت انتخاب کردی (Gemini/OpenRouter/OpenAI/Custom) به‌جای دیگه‌ای ارسال نمی‌شن. جزئیات کامل در فایل PRIVACY.md همراه افزونه.
این کار کلیدهای API، تنظیمات، آمار مصرف، دیکشنری و حافظهٔ ترجمهٔ ذخیره‌شده روی این دستگاه رو برای همیشه پاک می‌کنه، قابل بازگشت نیست.

گزارش فنی

گزارش فنی آخرین رویدادهای افزونه روی همین دستگاه است. برای پشتیبانی، گزارش را کپی کن و برایمان بفرست. تست Live و تست صدای دوبله فقط مسیر دوبله را امتحان می‌کنن؛ تست کلیدهای Gemini، OpenRouter و OpenAI در بخش «کلیدهای API» است.
هنوز تستی اجرا نشده است.

راهنما و پشتیبانی

برای گزارش مشکل، ابتدا وارد حساب شو تا تیکت ثبت کنی؛ یا مستقیم در تلگرام پیام بده.

برای کنترل سریع زیرنویس، موتور ترجمه و استایل از پاپ‌آپ افزونه استفاده کن؛ کلیدها و سرویس‌ها را اینجا در «تنظیمات» وارد کن.

من مبین‌ام، سازنده Subify

داستان Subify از زمانی شروع شد که داشتم زبان اسپانیایی یاد می‌گرفتم و برای یادگیری و آمادگی کنکور، خیلی از ویدیوهای آموزشی YouTube رو می‌دیدم. یه مشکل بزرگ داشتم؛ زبانم هنوز اون‌قدر خوب نبود که بتونم همه ویدیوها رو راحت بفهمم

خیلی از ویدیوها ترجمه فارسی نداشتن، بعضی از زیرنویس‌ها هم قابل‌فهم نبودن و پیدا کردن دوبله مناسب تقریباً غیرممکن بود. برای فهمیدن هر جمله باید ویدیو رو متوقف می‌کردم، متن رو کپی می‌کردم، می‌رفتم سراغ مترجم یا یه ابزار هوش مصنوعی و بعد دوباره برمی‌گشتم به ویدیو. چند دقیقه بعد هم همین داستان تکرار می‌شد!

به‌جای اینکه روی یادگیری تمرکز کنم، مدام بین ویدیو و ابزارهای مختلف جابه‌جا می‌شدم. خلاصه اینکه یادگیری خودش تبدیل شده بود به یه پروژه جداگانه

اما چیزی که باعث شد این موضوع رو جدی‌تر دنبال کنم، هستی بود. اون هم با همین مشکل روبه‌رو بود و وقتی دیدم این چالش فقط برای من نیست، بیشتر به این فکر کردم که چرا نباید راه ساده‌تری برای فهمیدن ویدیوها وجود داشته باشه؟

همین شد که تصمیم گرفتم Subify رو بسازم

راستش اون موقع فکر نمی‌کردم این ایده تا این اندازه بزرگ بشه. هدفم این بود که ابزاری داشته باشم که ترجمه و فهمیدن ویدیوها رو راحت‌تر کنه، بدون اینکه لازم باشه برای هر جمله سراغ چند ابزار مختلف برم

از هستی هم واقعاً ممنونم، چون تجربه مشترکمون نقش مهمی در جدی شدن این ایده داشت. شاید بدون اون هم یه روزی به فکر ساخت چنین ابزاری می‌افتادم، اما دوست دارم همیشه یادم بمونه که این مسیر چطور شروع شد

ولی داستان همین‌جا تموم نشد

هرچی بیشتر روی Subify کار کردم، بیشتر متوجه شدم که مشکل فقط ترجمه ویدیو نیست

کسی که زبان یاد می‌گیره، ممکنه به توضیح گرامر نیاز داشته باشه. یکی دیگه دنبال معنی یه کلمه‌ست، یکی می‌خواد با هوش مصنوعی صحبت کنه و سؤال بپرسه و یکی هم ترجیح می‌ده به‌جای خوندن زیرنویس، ویدیو رو به زبان خودش بشنوه

از طرفی، هوش مصنوعی هر روز امکانات جدیدتری در اختیارمون می‌ذاره و به نظرم حیف بود Subify رو به یه ابزار ساده برای ترجمه زیرنویس محدود کنم

برای همین، کم‌کم شروع کردم به گسترش ایده اولیه و ساخت قابلیت‌های جدید. چیزی که با یه نیاز شخصی شروع شده بود، به محصولی تبدیل شد که امروز بخش‌های مختلفی از یادگیری زبان، ترجمه و تعامل با هوش مصنوعی رو کنار هم قرار می‌ده

الان Subify فقط برای ترجمه ویدیو نیست. توی وب‌اپلیکیشنش می‌تونی با هوش مصنوعی چت کنی، گرامر زبان یاد بگیری، معنی و ترجمه لغات رو پیدا کنی، از ابزارهای یادگیری زبان استفاده کنی و با کمک قابلیت‌های ترجمه و دوبله هوش مصنوعی، محتوای ویدیویی رو راحت‌تر دنبال کنی

در کنار این‌ها، قابلیت‌هایی مثل زیرنویس دوزبانه، ترجمه زنده در محیط‌های پشتیبانی‌شده و خروجی گرفتن از زیرنویس‌ها هم بخشی از امکانات Subify هستن

از همون اول هم نمی‌خواستم Subify فقط به YouTube محدود بمونه. هدفم این بوده که تجربه استفاده از محتوای چندزبانه رو در پلتفرم‌های مختلف ساده‌تر کنم؛ از ویدیوهای آموزشی و دوره‌های آنلاین گرفته تا محتوای سرگرمی و چیزهایی که هر روز توی اینترنت می‌بینیم

البته ساختن چنین محصولی مسیر ساده‌ای نیست. از توسعه و طراحی گرفته تا کار با مدل‌های هوش مصنوعی، پیدا کردن راه‌حل‌های بهتر و بهتر کردن تجربه کاربر، هنوز کلی چیز برای یاد گرفتن و بهتر کردن وجود داره

اما دقیقاً همین بخش ماجراست که برام جذابه؛ اینکه یه ایده رو مرحله‌به‌مرحله به محصولی تبدیل کنم که واقعاً به درد آدم‌ها بخوره

هدفم از ساخت Subify چیه؟

وقتی به این موضوع فکر می‌کنم، می‌بینم آدم‌های زیادی در سراسر دنیا به محتوایی دسترسی دارن که نمی‌تونن به‌خوبی ازش استفاده کنن، فقط به این دلیل که به زبان دیگه‌ایه

ممکنه یه نفر بخواد از یه دوره آموزشی چیزی یاد بگیره، یکی دنبال یادگیری یه زبان جدید باشه و یکی دیگه فقط بخواد فیلم یا ویدیوی موردعلاقه‌ش رو بدون دردسر بفهمه

من دوست دارم Subify کمک کنه این فاصله کمتر بشه

تمرکز فعلی من روی بهتر کردن تجربه کاربران فارسی‌زبانه، اما چشم‌اندازم خیلی فراتر از اینه. می‌خوام Subify به یه محصول بین‌المللی تبدیل بشه که آدم‌ها با زبان‌های مختلف بتونن ازش استفاده کنن و برای یادگیری، ترجمه و درک محتوای جهانی بهش دسترسی داشته باشن

شاید اولش فقط می‌خواستم خودم راحت‌تر زبان یاد بگیرم، اما حالا هدفم اینه که آدم‌های بیشتری بتونن از محتوایی استفاده کنن که قبلاً به خاطر زبان براشون سخت یا حتی غیرقابل‌دسترس بوده
