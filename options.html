مدیریت پیشرفتهٔ ترجمهٔ زیرنویس و گزارش فنی

Lite — فقط ترجمهٔ زیرنویس
این صفحه فقط برای تنظیمات پیشرفته است.

کلیدهای API، انتخاب موتور ترجمه و استایل زیرنویس از اینجا حذف شده‌اند و از داخل Popup مدیریت می‌شوند.

سرویس‌های API سفارشی

افزودن/ویرایش اینجا انجام می‌شه (نه توی Popup) چون درخواست اجازهٔ دسترسی به دامنهٔ سرویس یه پاپ‌آپ مرورگری باز می‌کنه، و Popup خود افزونه با باز شدن اون پاپ‌آپ بسته می‌شه و هرچی توش تایپ کرده بودی از دست می‌ره. این صفحه یه تب عادیه، این مشکل رو نداره.

عیب‌یابی و گزارش

تست کلیدهای Gemini، OpenRouter و OpenAI داخل Popup انجام می‌شود.
هنوز تستی اجرا نشده است.

آمار مصرف و برآورد هزینه

اعداد زیر مصرف واقعیِ همین افزونه‌ست. برای برآورد هزینه، نرخ هر سرویس رو خودت جلوش وارد کن — چون قیمت‌ها بین سرویس‌ها/مدل‌ها فرق داره و مدام تغییر می‌کنه، اینجا هیچ عددی حدس زده نمی‌شه؛ فقط مصرف تو در نرخی که خودت می‌دی ضرب می‌شه.

هنوز هیچ زیرنویسی ترجمه نشده.

حریم خصوصی و داده‌ها

کلیدهای API و تمام تنظیمات فقط روی همین دستگاه (Storage محلی مرورگر) ذخیره می‌شن و جز به همون سرویسی که خودت انتخاب کردی (Gemini/OpenRouter/OpenAI/Custom) به‌جای دیگه‌ای ارسال نمی‌شن. جزئیات کامل در فایل PRIVACY.md همراه افزونه.
این کار کلیدهای API، تنظیمات، آمار مصرف، دیکشنری و حافظهٔ ترجمهٔ ذخیره‌شده روی این دستگاه رو برای همیشه پاک می‌کنه — قابل بازگشت نیست.

برای کنترل سریع زیرنویس، Provider، کلیدها و Style از Popup افزونه استفاده کن.
